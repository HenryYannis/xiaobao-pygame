## 🎨 核心编写准则 (五大法则)

为确保教学的零起点友好性与代码的高可读性，本仓库所有课程代码严格遵循以下 **五大核心法则**：

1. **函数名与变量名全中文化**：所有自定义变量名、函数名直接使用中文汉字命名（Python 3 原生完整支持 UTF-8 标识符），消除初学者对英语词汇的恐惧感，让代码如读句子一样直观明了。
2. **精准对齐的行尾注释**：
   - 注释统一在行尾使用空格**纵向列对齐**（通常在第 50~55 列左右），代码在左、讲解在右，清爽有序。
   - 显而易见的常规代码行（如导包、`pygame.init()`、简单赋零初始化等）拒绝画蛇添足；注释严格聚焦于坐标换算、核心算法、Pygame 机制与增量行。
3. **课时控制与渐进结构 (3-5课，取消硬性行数限制)**：不设硬性代码行数限制，以逻辑完整、讲解清晰为核心；每个小游戏严格控制在 **3-5 节课** 内完成，由浅入深，让学生快速构建出好玩作品并收获满满成就感。
4. **零外部素材与默认字体原则 (防报错与防乱码)**：
   - 纯使用 `pygame.draw` 绘制几何图形，严禁导入外部图片和音频素材，彻底避免路径报错。
   - 字体统一采用 Pygame 原生内置默认字体 `pygame.font.Font(None, 36)`，不加载系统字体，画面中显示的内容全部采用标准英文（如 `SCORE`、`GAME OVER`、`YOU WIN!`、`TIME UP!` 等）。
5. **增量行尾标注规范**：新课相较于前一课新增的代码行，在行尾注释紧随特殊标注：`# 新增变量：`、`# 新增函数：` 或 `# 新增代码：`，方便一眼看出每节课的增量演进。

## 🚀 快速开始

### 1. 运行环境配置
确保您的电脑上已安装 **Python 3.10 ~ 3.12（强烈推荐 Python 3.12）**。
> ⚠️ **新手注意**：请**不要使用 Python 3.14 及以上测试版**，因其暂无官方预编译轮子（Wheel），会导致 Pygame 安装失败。

然后，打开终端并运行以下命令，一键安装唯一的第三方库依赖 **Pygame**：

```bash
pip install -r requirements.txt
```

### 2. 交互式游戏图形运行菜单 (强烈推荐)
为了方便直观地浏览和启动各课时游戏，我们使用 **Pygame** 开发了一个精美的 **GUI 启动器**。在仓库根目录下运行以下命令即可启动：

```bash
python run_launcher.py
```

启动器特色：
* **精美暗黑主题**：支持平滑的鼠标悬停高亮、发光边框与选项选中状态。
* **分栏布局**：左侧为 18 个游戏列表，右侧为当前选中的课时卡片。卡片支持友好解析（如 `Lesson 1 - 气泡浮现`）和真实文件名对照展示。
* **快捷链接**：左下角常驻作者和网址，点击可自动通过浏览器跳转至官网。
